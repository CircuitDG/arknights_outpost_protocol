# 一、游戏概述

## 1.1 项目简介

《明日方舟：废土前哨协议》是一款基于《明日方舟》世界观的**上帝视角硬核生存建造游戏**，融合了《僵尸毁灭工程》的生存压力与Roguelike的重开价值。

游戏设定在泰拉大陆某座被天灾摧毁、与罗德岛本舰失联的**废弃移动城市碎片**上。玩家将扮演从切尔诺伯格事件后苏醒的**博士**——罗德岛的高层领导、矿石病治疗与天灾研究方面的顶尖学者——带领身边仅剩的数名干员，在这片被源石结晶覆盖的废土上挣扎求生。

> **一句话卖点**：在随机毁灭的废土上，用博士的头脑和干员的性命，搏一个不确定的明天。

## 1.2 核心体验

- **高压生存爽感**：每一份资源都弥足珍贵，每一次出门探索都要权衡风险。像《僵尸毁灭工程》一样让人手心冒汗。
- **"指挥官"的抉择快感**：你不再是抽卡看录像的"摄像头博士"，而是必须亲自冲进废墟、在干员头顶下达移动指令的战场活地图。
- **肉鸽式的宿命感**：每一局都是全新的城市布局和敌袭组合。博士若死亡则整局清零，但"博士的经验"会保留，让每一次重开都有新策略。
- **干员羁绊**：干员是博士的命运共同体，他们不会永久死亡，但每一次受伤都让你心疼——保护他们，就是保护你在废土上唯一的家人。
- **养成正反馈**：干员会升级、防御塔能强化，每一次付出都有看得见的回报。
- **藏品收集的惊喜感**：每一次探索都可能捡到改变战局的"废土遗物"——它们可能是前文明的黑科技、罗德岛遗失的装备、甚至是泰拉大陆上流传的传说之物。收集藏品、搭配组合、解锁隐藏剧情，为每一次重开注入新的可能性。

## 1.3 目标平台

PC（Steam / 独立游戏发布）

# 二、世界观设定

## 2.1 泰拉世界与天灾

游戏舞台位于**泰拉大陆**——一个居民带有各种动物特征的亚人类世界。这片大地上频繁发生被称为 **"天灾"** 的自然灾害，包含暴风、雪灾、洪水及陨石坠落等现象。天灾的规律并非完全无迹可寻，泰拉大陆存在被称为 **"天灾安全带"** 的相对安全区域。

每一次天灾的发生都会对人类造成难以预估的损失，同时也带来了 **"源石"** 。源石是泰拉世界的命脉，它诞生了利益、力量、痛苦、仇恨以及名为"感染者"的悲剧。人们利用源石中的能量发展工业，源石已然成为整个社会的根基。

## 2.2 源石与矿石病

**源石**是一种黑色半透光的矿物，具有活性化、适应性和自然增长三大特性。活性化状态下会释放高密度能量并产生感染性颗粒。

**矿石病**（多发性源石感染综合症）是由活性源石感染造成的不治之症，在这片大地上尚未发现过治愈并且确认的先例。感染者能以体内源石结晶为媒介直接施放源石技艺，但使用源石技艺可能导致病情恶化。

**博士的特殊性**：由于研制期间对源石定下的机制，博士无法被源石感染。博士的血液甚至被制成血清来抑制他人的矿石病。

## 2.3 博士（玩家角色）

博士是罗德岛的高层领导、三大创始人之一。其真实身份是前文明研究团队的成员，代号 **"预言家"** 。在切尔诺伯格事件中被罗德岛干员唤醒后，博士失去了过往一切记忆，但保留了深刻的战术指挥能力与源石知识。

**博士的核心设定**：
- 矿石病治疗与天灾研究方面的顶尖学者
- 拥有生物学、神经工程学博士学位
- 除科研天赋与战术指挥之外**没有战斗能力**
- 是罗德岛陆行舰系统最高级别的权限持有者

在本作中，博士**无法攻击**，必须依靠干员保护自己。

## 2.4 罗德岛

**罗德岛**是博士所属的医疗组织。在游戏中，玩家作为罗德岛的核心成员，带领干员战斗，处理源石带来的争端，救助感染者人群。

在《废土前哨协议》的设定中，博士与罗德岛本舰失联，被困在废弃移动城市碎片上。随身携带的只有一部搭载 **PRTS（原生罗德岛终端服务）系统** 的便携终端——它将成为博士在废土上的唯一科技依靠。

## 2.5 视觉风格

- **视角**：2.5D 固定上帝俯视角
- **色调**：阴郁冷色调为主（灰蓝、墨绿、锈褐色），突出废土的荒凉与压抑
- **高光时刻**：干员释放源石技艺时出现高饱和度的鲜艳色块（如红色的"真银斩"弧光、蓝色的医疗法术光效），形成强烈视觉反差
- **地图元素**：源石晶簇从柏油路面刺出，锈蚀的乌萨斯重卡横在路中央，废弃建筑上爬满源石结晶
- **藏品特效**：获得藏品时屏幕边缘闪烁对应稀有度的光晕（白/蓝/橙），并伴有音效反馈


# 三、核心玩法系统

## 3.1 昼夜循环与生存节奏

游戏以**"天"**为基本生存单位，每个昼夜循环包含四个阶段：

| 时段 | 游戏内时间 | 核心玩法 | 压力源 |
|:---|:---|:---|:---|
| **探索期** | 06:00 - 17:00 | 博士带队出门，根据地图上的地标图标规划路线，搜刮资源、营救干员、**寻找藏品** | 搜索有噪音，可能提前惊动敌人；博士体力有限 |
| **建设期** | 17:00 - 21:00 | 返回前哨站，利用建材升级围墙、制造炮台、布置陷阱 | 时间紧迫，须在倒计时结束前完成防线布局 |
| **防守期** | 21:00 - 05:00 | 敌人从地图边缘向你的前哨站发起总攻。操控干员走位、释放技能、启动炮塔 | 干员疲惫值递增，心情过低可能拒绝执行指令 |
| **休整期** | 05:00 - 06:00 | 战后清算：治疗伤员、修理装备、分配食物。结算当日存活奖励 | 若食物不足，全体干员次日带"饥饿Debuff" |

## 3.2 操作模式

### 博士操作

- **WASD**：控制博士移动
- **空格键**：奔跑（消耗体力，体力耗尽强制减速并发出喘息声吸引敌人）
- **E键**：拾取/互动
- **鼠标左键**：与场景中的物体交互（开门、搜索等）

### 干员指挥（RTS式）

- **鼠标右键**：点击地面或敌人，干员以"松散阵型"移动到指定位置
- **到达后自动攻击**：进入射程的敌人会被干员自动攻击
- **F1-F4**：对应1-4号干员的主动技能（手动精准施放）
- **自动施放开关**：在设置中开启后，AI会在敌人密集或友军血量低于30%时自动开启技能（智能程度有限，不会存技能躲BOSS大招）
- **G键**：切换"集结模式"（干员聚在博士身边）和"散开模式"（干员自动寻找附近掩体）

### PRTS终端辅助

博士的便携终端搭载PRTS系统，提供以下功能：

- 实时显示干员状态（血量、心情、体力）
- 地图标记与导航
- 敌袭预警（"检测到西南方向感染生物群正在靠近"）
- 生存日志记录（干员气泡对话存档）
- **藏品图鉴**（查看已解锁藏品及其效果）

## 3.3 地图与探索

### 无缝大地图

一张巨大的无缝俯视角地图（约等于《僵尸毁灭工程》的"诺克斯县"大小），无需读图。包含多种生态区域：

| 区域类型 | 特征 | 风险等级 |
|:---|:---|:---|
| 废弃城区 | 高资源、高危险，源石结晶遍地 | ★★★★★ |
| 荒野公路 | 视野开阔，缺乏掩体，易遭远程袭击 | ★★★ |
| 工业废墟 | 建材丰富，内部狭窄，转角遇敌 | ★★★★ |
| 天灾禁区 | 随机刷新，持续掉血，藏有极品物资与藏品 | ★★★★★ |
| 天灾安全带 | 相对安全区域，适合建立前哨站 | ★ |

### 地标全显示

**开局地图全开**，所有重要地标（超市、警局、加油站、药房、修车厂）直接以图标显示。玩家可像看旅游地图一样提前规划"今日扫货路线"。

### 探索机制

- 博士和干员以小队阵型在地图上连续行走
- 博士拥有**体力值**（跑步消耗，走路恢复）
- 地图标记"已探索区域"和"未探索迷雾"
- **不显示敌人位置**——需通过音效提示或高星干员"开视野"来感知危险
- **藏品搜索**：部分特殊地点（如图书馆、实验室、古董店）有更高概率发现藏品

## 3.4 前哨站系统

地图上共有 **4个固定大型前哨站**（分别位于地图东南西北），特性如下：

- **占领条件**：必须清空前哨站内的"源石结晶巢穴"（小型Boss战）
- **永久升级**：一旦占领，该前哨站的围墙、工作台、防御工事**永久保留**（不会因新开肉鸽局而消失）
- **天灾损坏**：前哨站可能因"天灾事件"随机损坏，需修缮
- **搬家成本**：可选择白天"搬家"到另一个前哨站，但旧的防御工事会随时间逐渐废弃
- **藏品陈列室**：前哨站内可建设"藏品陈列室"，用于展示本局收集的藏品（视觉反馈，无实际效果加成）

> **设计理念**：像《腐烂国度》一样，有明确的"家园归属感"和长期经营动力。

## 3.5 干员系统

### 3.5.1 干员职业

干员分为**先锋、近卫、重装、狙击、特种、医疗、术师、辅助**八种职业类型。不同职业拥有专属特性与战斗定位。

| 职业 | 核心定位 | 在本作中的作用 |
|:---|:---|:---|
| 先锋 | 最早进入战场，阻挡敌人 | 前期防守主力，阻挡数高 |
| 近卫 | 素质全面，清除近处威胁 | 主力输出，绕后切后排 |
| 重装 | 高防御，阻挡强力敌人 | 正面扛线，保护博士 |
| 狙击 | 远程物理攻击 | 高台输出，清理远程敌人 |
| 术师 | 源石技艺法术攻击 | 高台法术输出，破甲 |
| 医疗 | 治疗友军 | 唯一回复手段，不可或缺 |
| 辅助 | 增益/控制 | 减速、增伤等战术支援 |
| 特种 | 特殊作战能力 | 应对特殊地形/敌人 |

### 3.5.2 干员获取

- **初始开局**：每局固定从 **2名随机低星干员** 开始
- **地图营救**（核心来源）：地图上刷新 **"罗德岛求救信标"**（蓝色感叹号），接近后触发营救任务（限时清怪/保护目标），完成后干员加入
- **局外天赋影响**：解锁的"干员信赖回声"越多，遇到高星干员信标的概率越高
- **特殊事件**：极小概率遇到 **"流浪商人"**（如大帝或可颂），可用资源"购买"随机干员招募机会

### 3.5.3 干员状态系统

每位干员拥有以下核心属性：

| 属性 | 说明 |
|:---|:---|
| 生命值 | 归零则进入"战斗不能"状态 |
| 心情值 | 基础100，影响战斗效率。低心情可能触发负面特质 |
| 体力值 | 连续战斗消耗，耗尽后攻速下降 |
| 信赖度 | 随共同作战天数提升，可解锁额外剧情与属性加成 |

### 3.5.4 干员损伤与恢复

**原则：干员是"固定资产"，永不永久减损。**

**① 血量归零 → "战斗不能（濒危）"**

- 干员倒地，停止攻击，进入 **"红色濒危"** 状态
- 敌人会无视倒地者（不再继续攻击）
- **博士的抉择（30秒倒计时）**：
  - **急救**：博士亲自跑到干员身边，消耗1个 **"急救绷带"**（稀缺物资）紧急救治。成功后干员恢复20%血量，进入 **"重伤休养"** 状态
  - **紧急撤离**：点击干员头像选择撤离，该干员本局剩余时间无法出战，但**下一局满血回归**（无任何惩罚）
  - **放弃**：倒计时结束未操作，系统自动执行"紧急撤离"
- **干员永远不会死亡，也不会从未来局中移除**

**② 血量低于10% → "精神创伤"**

- 心情值暴跌 **50点**
- 附加 **"创伤应激"** 临时Debuff：攻击力-15%，移动速度-10%，持续 **3个游戏日**
- **恢复机制（完全可逆）**：
  - 在前哨站休息室休息1整天（不参与探索），心情每日恢复20点
  - 消耗 **"源石糖果"** 或 **"热水壶"** 快速恢复心情
  - 心情回满后，"创伤应激"Debuff自动消失，**属性完全恢复，绝无永久上限降低**

### 3.5.5 干员升级系统

干员不再是一成不变的，通过废土上的战斗与历练，他们可以变得更强。

**① 经验获取途径**

| 行为 | 获得经验 | 说明 |
|:---|:---|:---|
| 击杀敌人 | +5~50（依敌人强度） | 最后一击者获得全额经验，助攻者获得50% |
| 参与防守波次 | +20/波次 | 存活至天亮即结算 |
| 搜索资源点 | +5/次 | 仅限博士或干员亲自搜索 |
| 建造/升级设施 | +10/次 | 参与建设的干员获得 |
| 营救新干员 | +30/次 | 所有小队成员获得 |
| 在休息室休养 | +10/天 | 干员休息时也会缓慢成长 |

**② 升级效果**

| 等级 | 所需累计经验 | 效果 |
|:---|:---|:---|
| Lv.1 | 0（初始） | 基础属性 |
| Lv.2 | 100 | 攻击力 +10%，生命值 +10% |
| Lv.3 | 250 | 攻击力 +10%，生命值 +10%，解锁**被动天赋①** |
| Lv.4 | 450 | 攻击力 +15%，生命值 +15%，技能冷却 -10% |
| Lv.5 | 700 | 攻击力 +15%，生命值 +15%，解锁**被动天赋②** |
| Lv.6（满级） | 1000 | 攻击力 +20%，生命值 +20%，技能冷却 -20%，解锁**专属羁绊对话** |

> **数值平衡理念**：干员升级带来的数值成长是**边际递减**的——从 Lv.1 到 Lv.3 提升巨大，后面更多是锦上添花。真正的战术变化来自**被动天赋**的解锁，而非单纯的数值碾压。

**③ 被动天赋（示例）**

每个干员拥有 2 个独特的被动天赋，分别在 Lv.3 和 Lv.5 解锁：

| 干员 | 天赋①（Lv.3） | 天赋②（Lv.5） |
|:---|:---|:---|
| **芬（先锋）** | 《冲锋号令强化》：技能持续期间，自身与周围2格内友军攻速+15% | 《前线补给》：每击杀3个敌人，回复自身5%生命值 |
| **玫兰莎（近卫）** | 《暗夜猎手》：对生命值低于40%的敌人造成额外25%伤害 | 《源石亲和》：攻击时有10%概率不消耗攻击间隔（连击） |
| **安塞尔（医疗）** | 《战地救护》：治疗量+15%，且治疗目标获得2秒内伤害减免10% | 《远程支援》：治疗范围+1格 |
| **克洛丝（狙击）** | 《精准射击》：对飞行单位造成额外30%伤害 | 《耐心狙击》：若3秒未移动，攻击力叠加+5%（最多+25%） |

**④ 干员升级与肉鸽循环**

- **单局内保留**：本局内获得的经验值**实时累加**，升级效果**立即生效**
- **局外继承（轻量化）**：干员死亡/撤离后，下局开局时**保留 30% 的累计经验**（向下取整）。即：若本局芬达到了 Lv.4（450经验），下局开局芬从 Lv.2（135经验）起步。
- **设计意图**：让玩家有培养的**连续性**，但又不至于滚雪球过度。强干员需要多局积累才能满级，与"干员信赖回声"系统形成双重养成线。

### 3.5.6 干员信赖回声（局外养成）

每成功存活一天，且无干员触发"紧急撤离"（即成功保护了所有人），获得 **"信赖点数"**。累计可用于：

- 解锁该干员的**初始自带装备**（如开局给玫兰莎配一把好刀）
- 解锁干员在篝火时的**特殊二创对话彩蛋**
- 提升该干员在后续局中的**初始心情值**

## 3.6 战斗系统

### 塔防部分（战前准备）

- 利用建材在前哨站外围搭建 **弩炮台、减速凝胶、高台护栏**
- 干员站在高台上攻击范围变大，且不会被地面近战敌人攻击
- 博士负责给炮塔装填弹药（需要亲自跑过去）

### RTS动作部分（实时操控）

- **绕后切后排**：当敌方"大锤哥"或高甲单位突破防线时，手动拖拽近卫干员绕后攻击
- **躲避AOE**：敌方释放大范围源石技艺（红圈预警）时，必须手动拉走范围内干员，否则秒杀
- **博士的战术支援**：投掷 **"闪光弹"**（眩晕）或 **"诱饵雷"**（引向炸药桶），这是唯一不消耗干员体力的硬控手段

> **设计理念**：平时像塔防挂机攒费，高压波次像《盟军敢死队》一样极限手操走位。

## 3.7 生存物流系统

废土上不能靠"魔法搬砖"。为了解决"采集资源如何带回安全屋"的问题：

- **博士背包**：格子有限，只能装食物、药品、图纸等小型物品
- **手推车**：开局自带一辆，可装10单位建材（木材/铁皮）
- **源石动力三轮车**：探索废弃车库可获得。容量更大，但消耗源石燃料，且**噪音极大，容易引来尸潮**
- **物流策略**：建材必须装车推回前哨站才能用于建造。需规划"采集路线"和"撤退路线"

## 3.8 防御塔升级系统

防御塔不再是"建好就完事"的一次性设施。在废土上，你需要投入资源来让它们跟得上敌人的强度。

### 3.8.1 防御塔类型

| 塔名 | 基础功能 | 解锁条件 |
|:---|:---|:---|
| **弩炮台** | 单体物理攻击，射速中等 | 开局即解锁 |
| **减速凝胶塔** | 发射凝胶，使敌人移速 -50% | 搜索到"凝胶配方" |
| **源石爆裂塔** | 范围法术伤害（AOE） | 搜索到"源石回路" |
| **高台护栏** | 提供高台位，干员站上去攻击范围+2格 | 开局即解锁 |
| **医疗无人机平台** | 自动治疗周围友军（低效） | 营救至少1名医疗干员后解锁 |
| **铁丝网墙** | 经过的敌人受到持续伤害并减速 | 搜索到"工业图纸" |

### 3.8.2 防御塔升级效果

每座塔可以升级 **3 次**，每次升级需要消耗**建材 + 特殊物资**：

| 等级 | 所需资源 | 效果提升 |
|:---|:---|:---|
| **Lv.1（基础）** | 初始 | 基础属性 |
| **Lv.2** | 木材×15 + 铁皮×8 | 攻击力/效果 +30%，耐久度 +20% |
| **Lv.3** | 木材×30 + 铁皮×20 + 源石结晶×2 | 攻击力/效果 +30%，耐久度 +30%，**解锁一个附加效果** |
| **Lv.4（满级）** | 木材×50 + 铁皮×35 + 源石结晶×5 + 稀有元件×1 | 攻击力/效果 +40%，耐久度 +40%，**附加效果增强，弹道特效升级** |

### 3.8.3 各塔升级附加效果（Lv.3 解锁）

| 防御塔 | Lv.3 附加效果 | Lv.4 附加效果增强 |
|:---|:---|:---|
| 弩炮台 | 20% 概率**穿透射击**（命中一个敌人后继续飞行命中后方敌人） | 穿透概率提升至40%，且穿透后伤害不衰减 |
| 减速凝胶塔 | 凝胶爆炸时对范围内敌人造成**微量源石伤害**（每秒5点） | 伤害提升至每秒15点，减速效果提升至-65% |
| 源石爆裂塔 | 爆炸后留下**源石地刺**，持续5秒，对经过敌人造成持续伤害 | 地刺持续10秒，范围扩大30% |
| 医疗无人机平台 | 治疗时会**驱散目标一个负面状态**（如减速、灼烧） | 治疗量+30%，驱散范围+1格 |

### 3.8.4 防御塔升级与肉鸽循环

- **单局内保留**：升级在当前局内永久有效
- **前哨站绑定**：防御塔升级**绑定前哨站**，而非全局共享。如果搬家到另一个前哨站，需要**重新升级**（但旧前哨站的塔会在你离开后逐渐废弃）
- **设计意图**：鼓励玩家选择"根据地"深耕，而非四处流浪。搬家是一种"战略性放弃"，代价是投入的升级资源。

### 3.8.5 "博士的战术笔记"系统

某些防御塔的升级配方和特殊建筑需要在废土上寻找**图纸**：

- 图纸分散在地图各处的**废弃实验室、军用仓库、天灾禁区**中
- 一旦获得图纸，**永久解锁**该塔的建造/升级选项（所有局通用）
- 图纸获取是局外成长的另一条线，与"博士天赋"形成平行养成体系

> **PRTS Wiki 备注**：博士除科研天赋与战术指挥之外没有战斗能力——但博士永远是个好学者。废土上的每一张图纸，都是博士"战术笔记"的一部分。

## 3.9 藏品系统

在《明日方舟》集成战略模式中，藏品是探索途中获得的主要物品，数量众多、效果各异。它们能显著增强队伍实力，不同的藏品组合可能产生意想不到的效果。

本作将完整继承并拓展这一系统，让废土上的每一次探索都充满"捡到宝"的惊喜。

### 3.9.1 什么是藏品？

**藏品**是博士在废土探索中获得的特殊物品。它们并非普通的生存物资（食物、建材），而是**具有独特被动效果的"遗物"**——可能是前文明的技术残留、罗德岛遗失的战术装备、泰拉大陆的传说之物，甚至是源石技艺的结晶。

一旦获得，藏品的**效果立即生效**，持续整局游戏。不同藏品的效果可以**叠加**，与干员技能、天赋形成联动。

> **集成战略原话**："收藏品的种类不同，效果繁多。您可以根据当次冒险目前已获得的收藏品的效果调整未来阵容规划，使冒险更加顺利。"

### 3.9.2 藏品稀有度

藏品分为三个稀有度等级，与集成战略设计一致：

| 稀有度 | 颜色 | 获取概率 | 效果强度 |
|:---|:---|:---|:---|
| **普通** | 白色 | 高（约60%） | 基础增益 |
| **稀有** | 蓝色 | 中（约30%） | 显著增益，可能改变战术 |
| **超稀有** | 橙色 | 低（约10%） | 强力增益，可能彻底改变玩法 |

### 3.9.3 藏品获取途径

| 获取方式 | 说明 | 概率 |
|:---|:---|:---|
| **搜索特殊地点** | 图书馆、实验室、古董店、博物馆等 | 较高 |
| **击败精英/Boss敌人** | 掉落物中有概率包含藏品 | 中等 |
| **完成营救任务** | 被营救的干员可能携带藏品作为谢礼 | 中等 |
| **天灾禁区探索** | 高风险高回报，必出稀有以上藏品 | 极高 |
| **流浪商人交易** | 用资源"购买"随机藏品 | 取决于资源 |
| **博士的便签** | 前一个轮回的笔记可能指出藏品位置 | 低 |

### 3.9.6 藏品图鉴（局外收集）

参考集成战略的"收藏品图鉴"系统，本作提供局外永久收集系统：

- **图鉴位置**：主菜单 → 博士终端 → 藏品图鉴
- **收集记录**：所有曾在游戏中获得过的藏品，**永久记录**（即使该局失败）
- **图鉴奖励**：收集达到特定数量时，解锁**全局永久加成**：
  - 收集10种：开局初始资源 +10%
  - 收集25种：解锁"藏品预言"功能——开局时可预览本局可能获得的前3个藏品类型
  - 收集50种：解锁"藏品传承"——每局开局时可选择1个已解锁的普通藏品**自带开局**
  - 收集全图鉴（全部藏品）：解锁**隐藏剧情**（博士的完整记忆碎片）

### 3.9.7 藏品与肉鸽循环

- **单局内**：藏品效果持续整局，死亡/删档后**全部消失**（藏品是"局内资源"）
- **局外继承**：
  - **藏品图鉴**永久保留（记录已解锁的藏品）
  - 达成图鉴收集目标后，获得全局永久加成（见3.9.6）
  - 超稀有藏品的"解锁记录"不会提升其出现概率——每一次获得超稀有都**值得截图庆祝**
- **设计意图**：藏品提供每局游戏的**独特体验**和**战术变数**，让重开不再是"一模一样的受苦"，而是"全新的可能性"。同时图鉴系统提供长期收集目标，延长游戏寿命。


# 四、Roguelike 循环

## 4.1 单局内（永久死亡）

**以下情况触发删档**：

- **博士死亡**：博士血条归零 → 整局存档永久销毁
- **前哨站核心被毁**：相当于"老家没了"，等同于失败
- **资源型卡死**：连续3天找不到食物或急救绷带，干员因"重度营养不良/感染"**强制罢工**（无法操控），博士孤身一人走向死亡

> **硬核定义**：干员不会死，但博士会死。物资会耗尽。绝望感来自"看着大家挨饿却无能为力"。

## 4.2 局外成长（让重开有意义）

**① 博士天赋树**

按存活天数结算 **"博士经验"**，可用于升级以下天赋：

| 天赋分支 | 天赋名称 | 效果 |
|:---|:---|:---|
| 生存本能 | 背包扩容 | 初始背包负重 +2/4/6 |
| 战术指挥 | 干员疾行 | 干员移动速度 +5%/10% |
| 废土幸运 | 搜刮好手 | 搜索到稀有物资概率提升 |

# 五、叙事与二创

## 5.1 叙事方式：纯文字气泡

采用**不打断游戏操作**的纯文字气泡对话，保持硬核生存的沉浸感。

**触发时机**：

- 干员捡到特定物品时（如捡到"吉他"，豆苗气泡："这个……能当武器吗？"）
- 遭遇特定天气（下雨时，克洛丝气泡："啊……狙击镜起雾了，躺平算了……"）
- 干员之间靠近时，随机触发职业互动（先锋和重装站一起："你挡着我输出了！""怪我咯？"）
- 前哨站休息时，干员之间触发日常对话
- **获得藏品时**：干员可能对藏品发表评论（如获得"真银斩剑谱"时，玫兰莎气泡："这个……银灰先生看到会说什么呢……"）

**呈现方式**：

- 气泡出现在干员头顶，**不影响游戏暂停**
- 对话内容存入 **"废土聊天记录"**（按J键翻阅）
- 某些气泡对话藏有 **"隐藏线索"**（如"我好像看到北边仓库有柴油发电机"）

## 5.2 "博士的便签"系统

每次肉鸽重开，你会随机捡到前一个"失败轮回"的博士留下的笔记，内容为玩梗的剧情碎片（如"千万别让能天使碰炸药桶"），既补充剧情，又给当前局提供实用小提示。

## 5.3 藏品叙事碎片

部分藏品附带**背景故事文案**（在获得时弹出或在图鉴中查看），用于补充泰拉世界的设定碎片：

- **"锈蚀的战术匕首"** 文案："上面刻着一行模糊的小字：'给最勇敢的先锋——你的教官。'——这或许是某位罗德岛教官留给学生的最后礼物。"
- **"源石结晶碎片"** 文案："这块碎片似乎来自某座被天灾吞噬的移动城市。它仍然在微微发热，仿佛还残留着那座城市最后的呼吸。"
- **"移动城市导航仪"** 文案："屏幕上有一条未完成的航线规划，终点被标记为'家'。那个坐标已经不存在了。"


# 六、敌人设计

基于《明日方舟》中的敌方单位设定，本作将出现以下类型敌人：

| 敌人类型 | 特征 | 玩家应对策略 |
|:---|:---|:---|
| 源石虫 | 低血量、群体出现 | 干员自动清理 |
| 步兵 | 整合运动普通地面近战单位 | 先锋阻挡+狙击输出 |
| 机动盾兵 | 装备制式盾牌，难以击溃 | 术师破甲或近卫绕后 |
| 双持剑士 | 高频攻击，压制低防单位 | 重装扛线 |
| 炮击组长 | 远程源石爆破，超远距离溅射 | 优先集火，拉走位躲AOE |
| 重装防御组长 | 精英单位，全套防具 | 术师+近卫配合击杀 |
| 碎骨 | 整合运动干部，源石爆破物 | 小Boss级别，需战术配合 |

> 随着存活天数增加，敌人波次的规模、种类和精英比例逐步提升。


# 七、第一天（Day 1）完整游玩流程

1. **08:00 开局**：博士从报废吉普中醒来，地图显示附近200m有"便利店"、500m有"警局"。身边只有【芬（先锋）】和【安塞尔（医疗）】。

2. **08:15 规划**：决定先去便利店（近，风险低）拿食物和撬棍，再去警局碰运气找手枪。

3. **10:00 便利店**：指挥芬撬开卷帘门（制造噪音），引来3只源石虫。自动战斗解决。搜到【罐头×3、矿泉水×2、手推车×1】。

4. **12:00 警局**：发现求救信标（蓝色感叹号），是【玫兰莎（近卫）】被锁在拘留室。清掉5只变异狗后营救成功，玫兰莎入队。在警局证物室发现 **【藏品：陈旧的狙击镜】**（普通品质）——狙击干员攻击范围+1格。

5. **14:00 图书馆**（途中经过）：搜索时触发事件，在书架暗格中发现 **【藏品：旧地图】**（普通品质）——地图上额外显示2个隐藏资源点。

6. **16:00 返回**：系统提示 *"今晚将有中型尸潮从东面来袭"*。选择距离最近的 **"东面前哨站"** 作为据点。

7. **17:30-20:30 建设**：用搜来的木材围出3面墙，造了1个弩炮台。玫兰莎部署侧翼，芬顶正面，安塞尔站高台（此时"陈旧的狙击镜"对安塞尔无效，因为他是医疗干员——玩家开始思考：下次是不是该找个狙击干员？）。

8. **22:00 防守战**：尸潮涌来。前期炮台挂机输出；中期出现"暴怒盾卫"（高甲），炮台刮痧。**手动拖拽玫兰莎绕后**触发背刺，同时手动开启芬的技能"冲锋号令"顶住正面。

9. **02:00 险情**：一只"源石爆破者"冲到博士面前，紧急按空格跑位，扔出"诱饵雷"将其引向炸药桶，炸死一片。

10. **05:30 黎明**：防守成功。3名干员全体"疲惫"，但无人重伤。芬因击杀12个敌人获得 **EXP +60**，从 Lv.1 升至 Lv.2。博士用剩余建材将弩炮台升到 Lv.2。

11. **06:00 结算**：系统结算：**存活Day 1，获得天赋点×1**。弹出气泡（芬）："博士，明天还能吃罐头吗？"芬的信赖度提升了。藏品图鉴更新：新增【陈旧的狙击镜】【旧地图】。
